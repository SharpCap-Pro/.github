## How SharpCap Pro Sits

SharpCap Pro does not replace the camera body, the mount, or the folder you already own. It sits beside them as a named imaging desk for one job: which live capture is running, which camera control still matches, and what the next person should read after the stream stops.

## Traffic Light

| Signal | On the SharpCap Pro board | What you do |
|--------|----------------------|-------------|
| Green | Named desk, short live frame list | Continue the same capture |
| Amber | Two cameras mixed in one stream | Split the set before you stack |
| Red | No title, no note, previews unsaved | Stop and name the capture first |
| Clear | Handoff written, live frames few | Close SharpCap Pro and leave the desk |

## Open Order

1. Open the last SharpCap Pro capture, not a new empty imaging desk.
2. Read the frame list and the last handoff.
3. Finish one visible live capture inside SharpCap Pro.
4. Write what changed, then close with fewer unsaved previews than you found.

## Desk Fit

| Who | What SharpCap Pro holds |

| Backyard | Live camera frames on the PC beside the mount |
| Shared desk | One SharpCap Pro profile per person |
| Review bay | Stacking preview checked before the next run |

## After a Week

A week in SharpCap Pro is not a bigger preview pile. It is the same title, a shorter live stream list, and a note that still makes sense on the next clear night. Take finished runs off the live set so the next visit starts on the camera that is still open.

## Sign-off

- [ ] The SharpCap Pro workspace name is short enough to scan
- [ ] Only the live camera is on the board
- [ ] A second person can read the handoff

## Field Note

SharpCap Pro is easier to trust when the imaging desk stays smaller than the preview folder it came from. Name the capture, keep the live stream, finish one visible run, and write what changed.
